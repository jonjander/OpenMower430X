# Open items

As this 430X stood on 2026-11-11. None of this is in an OpenMower guide. The 430X has no model guide for it.

## In progress

The cutting-height connector, slot polarity, and motor direction are documented in [Cutting height](cutting-height.md). Still open on that mechanism:

- The pulse count from one mechanical end to the other.
- Which of connector pin 1 and pin 2 is the red motor lead.
- The winding resistance on this mower.

## Still unknown

The connector that is still unknown is the 20-pin connector. No pin on it is assigned.

The display and the keyboard are not usable. They are not connected to the OpenMower boards.

The On/Off button is unknown too. This build has no switch that opens the supply, so the electronics stay on.

If this mower has headlights, they have not been looked at.
